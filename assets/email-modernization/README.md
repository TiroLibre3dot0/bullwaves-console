# Email Modernization Assets

Questa cartella raccoglie gli asset visivi destinati ai nuovi template email Bullwaves.

## Struttura

- `human-trust-product-proof/`
- `editorial-finance-premium/`
- `performance-cinematic/`
- `shared/`

## Uso Consigliato

1. Salvare qui i file originali o le versioni gia' ottimizzate
2. Tenere nomi coerenti con il manifest CSV
3. Caricare i file su hosting pubblico stabile
4. Aggiornare `asset-manifest-template.csv` con URL finale e stato
5. Passare gli URL finali nei template HTML

## Regole Pratiche

- evitare testo dentro le immagini
- preferire look premium e credibile, non stock generico
- ottimizzare peso e dimensioni prima dell'upload
- tenere una sola idea visiva forte per asset

## Nota

Da qui possiamo organizzare e preparare gli asset, ma non generare automaticamente immagini finali di qualita' senza una sorgente esterna o un tool dedicato. Il passaggio corretto e': scelta asset -> upload -> URL pubblico -> integrazione HTML.
